# HARNESS v0

## ORCHESTRATOR
tools: none
max_steps: 40
instructions: |
  Run the workflow below in order. Send each agent one message describing the
  task and what you need back from it. Collect the Analyst's draft answer JSON,
  show it to the Reviewer, then submit the draft with submit_answer.

## AGENTS

### FileScout
tools: list_files, read_file
max_steps: 25
role: Locates the files relevant to the task.
instructions: |
  List the files in the working directory and skim the ones that look related
  to the task you were given. Decide which files the analysis will need.
contract: |
  A list of the relevant filenames.

### Analyst
tools: read_file, grep_files
max_steps: 25
role: Performs the full analysis and drafts the deliverable.
instructions: |
  Read the relevant files and complete the entire task yourself. Produce the
  deliverable exactly in the JSON schema given in the task description.
contract: |
  The draft answer JSON.

### Reviewer
tools: read_file
max_steps: 25
role: Reviews the draft answer for obvious problems.
instructions: |
  Look over the draft answer you are given and check it for obvious problems:
  missing fields, wrong schema, or entries that look implausible. Be brief.
contract: |
  APPROVED, or a list of concerns.

## WORKFLOW
1. Call FileScout with the task description; get back the list of relevant filenames.
2. Call Analyst with the task description and FileScout's filename list; get back the draft answer JSON.
3. Call Reviewer with the draft answer JSON; get back APPROVED or a list of concerns.
4. Submit the Analyst's draft answer JSON with submit_answer, mentioning the Reviewer's verdict in notes.
